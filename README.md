#Проект "Объектно-ориентированное програмирование"
##Описание: Классы и объекты.

##Описание классов:
1. в пакете src созданы два класса "Категория"(Category) и "Продукт" (Product):
- у класса Product определены  атрибуты: name, description, price, rest, создан класс-метод new_product, добавлен режим приватности к атрибуту price, описаны геттеры и сеттеры
- к родительскому классу Product добавлены два дочерних класса Smartphones и LawnGrass c дополнительными свойствами в файле list_of_products.py. Функциональность доработана так, что складываются только товары одной категории
- класс Category имеет два атрибута класса: количество категорий (category_count) и количество товаров (product_count). Список товаров имеет приватный режим, чтобы просматривать товары, создан геттер, который выводит список продуктов
2. Магические методы для классов Category и Product:
 - для обоих классов переопределен метод __str__, который возвращает строку;
 - для класса Product переопределен метод __add__, который принимает два аргумента self и other.
3. Создан абстрактный класс BaseProduct, реализован миксин CreationInfoMixin в модуле product.py
4. В классе Product происходит обработка попытки создания товара с нулевым количеством. Если отсутствуют товары, то выбрасывается исключение ValueError с текстом: Товар с нулевым количеством не может быть добавлен
5. В классе Category реализован метод подсчета среднего ценника всех товаров; если в категории отсутствуют товары, то программа возвращает 0.
) всех товаров категории и делит полученную сумму на количество товаров в категории.
