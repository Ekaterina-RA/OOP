#Проект "Объектно-ориентированное програмирование"
##Описание: Классы и объекты.

##Описание классов:
1. в пакете src созданы два кдасса "Категория"(Category) и "Продукт" (Product):
- у класса Product определены  атрибуты: name, description, price, quantity;
- класс Category имеет два атрибута класса: количество категорий (category_count) и количество товаров (product_count).


##Установка
1. Клонируйте репозиторий git clone git@github.com:Ekaterina-RA/OOP.git
2. Установите зависимости poetry install


##Тестирование.
- Проект покрыт юнит-тестами Pytest. Чтобы запустить тесты с оценкой покрытия выполните команду: pytest
